Reads ComicInfo.xml from CBZ files to extract ComicVine IDs. Folders already in your library are skipped. Volumes without a ComicVine ID are shown but excluded from the import by default.

  • The import runs as a background task and handles rate limits automatically.
  • Files are not allowed to be directly in the root folder.

*Input has to be a folder (pattern) inside a root folder

When no ComicInfo ID is found, Kapowarr will search ComicVine by folder name. This is slow — one API call per untagged folder — and will hit the rate limit (200 req/hr) for large libraries. Each rate-limit pause adds 60 seconds per retry.
