Library Import

Scans folders for ComicVine IDs. Folders already in your library are skipped. Volumes without a ComicVine ID are shown but excluded from the import by default.

  • Without title matching: reads ComicInfo.xml only — instant, zero API calls, full rate limit available for importing.
  • With title matching: searches ComicVine by folder name for untagged files — uses the 200 req/hr limit at ~20 seconds per folder.
  • Files are not allowed to be directly in the root folder.

*Input has to be a folder (pattern) inside a root folder
